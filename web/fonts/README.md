# Fonts

The UI is drawn for the Nothing typefaces - NType82 Headline, NType82,
NType82 Mono and NDot 55. They belong to Nothing and are not in this
repository or in the release.

Without them EQ uses Windows' own fonts (Segoe UI, Consolas) and works the
same. If you have them, put these files in `%APPDATA%\EQ\fonts`:

    NType82-Headline.woff2
    NType82-Regular.woff2
    NType82Mono-Regular.woff2
    NDot-55.otf

and they are picked up the next time EQ starts.
